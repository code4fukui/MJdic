# MJ Dictionary - Mandarin Japanese Dictionary

中国語と日本語を相互に翻訳する辞書アプリケーションです。

## デモ
[MJ Dictionary](https://code4fukui.github.io/MJdic/)

## 機能
- 中国語または日本語のテキストを入力して単語を検索
- ピンイン表記と日本語訳を表示
- クリック可能な漢字を備えた、軽快な（Q弾）インターフェースを提供
- 中国語単語の音声読み上げ（Text-to-speech）をサポート

## 要件
ウェブベースのアプリケーションのため、特にありません。

## 使い方
ウェブサイトにアクセスし、テキストを入力して単語を検索します。

## データ / API
辞書データは [CC-CEDICT](https://cc-cedict.org/editor/editor.php?handler=Main) プロジェクトのものであり、CC BY-SAライセンスの下で提供されています。日本語訳は [DeepLAPI](https://github.com/code4fukui/DeepLAPI) ライブラリを使用して追加しました。
